# AI Assistance Disclosure

Odo uses AI tools as part of the development workflow. These tools may assist with drafting code, tests, documentation, examples, issue descriptions, and design notes.

AI assistance does not replace human review. AI-generated suggestions are treated as drafts and must be reviewed, edited, tested, and accepted by a human contributor before they become part of the project.

## Human responsibility

Project maintainers and contributors are responsible for:

- reviewing AI-assisted code for correctness and maintainability
- reviewing security-sensitive changes
- reviewing privacy-sensitive changes
- running relevant tests
- ensuring changes align with Odo’s project goals
- ensuring contributed code is compatible with the project’s license

## Security and privacy

Odo is access-layer software. Changes involving authentication, sessions, proxy behavior, cookies, logging, diagnostics, resource configuration, or user identity require particular care.

AI-generated suggestions should not be trusted as secure or privacy-preserving without review.

## Licensing

Contributors are responsible for ensuring that their contributions are compatible with Odo’s license.

Do not paste copyrighted third-party code into AI tools and submit the result as a contribution unless you have the right to do so and the resulting contribution is compatible with the project license.

## Disclosure standard

Contributors are not required to disclose every prompt or every use of AI assistance. However, contributors should disclose AI assistance when it is materially relevant to reviewing the contribution, especially for large generated changes, security-sensitive code, or substantial documentation.
